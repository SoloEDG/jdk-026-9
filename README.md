# 格间

安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

## 声音画布

每道题都可以编成一段循环作品：

- **行列即乐谱**：行决定音高（顶行最高，超出音阶度数自动跨八度循环），列决定节拍，从左到右完整扫描一次为一小节。已填格在对应拍位发声，标空与未知格只作休止，同列多格组成和弦。
- **可编排**：在棋盘下方的声音画布调整音阶、速度（BPM）、声部（钟铃 / 拨弦 / 柔垫）、基础八度与循环小节数，并保存到当前题目。
- **节奏稳定优先**：所有音符由 Web Audio 音频时钟前瞻调度。演奏中继续落笔不会立刻打断，修改挂起为新谱盘，在下一个小节边界整体生效——不会出现一半声部用旧谱、一半用新谱。界面会提示"修改尚未进入演奏"。
- **暂停 / 切题 / 撤销**：暂停通过挂起音频时钟实现，播放位置与声音始终对应；切题会停止演奏并丢弃未生效的谱盘；撤销后的棋盘变化同样在小节边界换谱。
- **浏览器拒绝音频或页面被挂起**：不补播、不积压任何声音。页面隐藏时自动暂停，恢复后需手动继续。
- **展柜回听与导出**：保存过声音的作品可在展柜回听，并通过 `OfflineAudioContext` 离线导出 WAV（8 / 16 / 30 秒，向上取整到完整小节）。导出与回听只读取保存时确认的不可变编排快照，实时编辑不会让成品中途换谱，也不会提前播放尚未解出的答案。
